# Phase 1 - Base fonctionnelle

## Objectifs
- garantir un schéma métier cohérent,
- ajouter les contraintes et index nécessaires,
- exposer des vues de synthèse pour le pilotage,
- préparer les flux client/produit/commande/facture.

## Livrables
1. Schéma métier complet et cohérent.
2. Vues de synthèse et vues métier.
3. Données de départ prêtes à l’usage.
4. Prototype web et API orientés sur les cas métier de base.

## Flux à valider
- création d’un client,
- ajout d’un produit,
- création d’une commande,
- génération d’une facture,
- enregistrement d’un paiement.
