# Prompt initial de specification

Crée les spécifications d'une application de gestion commerciale tournant sous Oracle et utilisant PL/SQL, SQL et Oracle APEX.

## Objectif

Rédiger une spécification fonctionnelle et technique complète pour une application de gestion commerciale adaptée à une entreprise moyenne ou grande, couvrant les modules métier, l’architecture, la sécurité, les données et le déploiement.

## Contexte

L’application doit permettre de gérer :
- les clients et prospects
- les produits et tarifs
- les commandes
- la facturation
- les paiements et encaissements
- les tableaux de bord et rapports

## Exigences attendues

1. Décrire les modules fonctionnels principaux.
2. Définir les entités de données et leurs relations.
3. Proposer une architecture Oracle avec PL/SQL, SQL et APEX.
4. Identifier les packages PL/SQL, procédures et fonctions utiles.
5. Proposer une organisation de sécurité et de rôles.
6. Définir un plan de déploiement et de cycle de vie.
7. Inclure une vision de l’intégration IA si nécessaire.

## Format souhaité

- résumé exécutif
- besoins fonctionnels
- besoins techniques
- modèle de données
- composants APEX
- packages PL/SQL proposés
- plan de test et de mise en production
